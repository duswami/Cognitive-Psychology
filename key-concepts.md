# Key Concepts Summary

## Behavioral
- Classical conditioning
- Operant conditioning
- Reinforcement (positive/negative)
- Punishment (positive/negative)
- Schedules of reinforcement
- Law of Effect
- Observational learning (Bandura)
- Self-efficacy
- Reciprocal determinism
- Behavior modification

## Cognitive
- Attention (selective, divided, sustained)
- Memory systems (sensory, working, long-term)
- Perception (bottom-up, top-down, Gestalt)
- Schemas (assimilation, accommodation)
- Problem-solving strategies
- Decision-making heuristics and biases
- Executive functions
- Language processing
- Cognitive development stages

## Overlaps / Integration
- Social cognitive theory bridges both (Bandura)
- Cognitive-behavioral therapy (CBT) combines cognitive restructuring with behavioral techniques
- Habit formation involves both conditioning and cognitive processes (cues, routines, rewards)
