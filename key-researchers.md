# Key Researchers

## Behavioral Psychology
- **Ivan Pavlov** (1849-1936): Classical conditioning experiments with dogs.
- **John B. Watson** (1878-1958): Founded behaviorism; Little Albert experiment.
- **B.F. Skinner** (1904-1990): Operant conditioning; Skinner box; radical behaviorism.
- **Edward Thorndike** (1874-1949): Law of Effect; puzzle box experiments.
- **Albert Bandura** (1925-2021): Social learning theory; Bobo doll experiment; self-efficacy.

## Cognitive Psychology
- **Ulric Neisser** (1928-2012): Authored "Cognitive Psychology" (1967).
- **George A. Miller** (1920-2012): Working memory capacity (7±2).
- **Alan Baddeley** (1934-): Working memory model.
- **Endel Tulving** (1927-2023): Episodic and semantic memory.
- **Daniel Kahneman** (1934-): Heuristics, biases, prospect theory (Nobel 2002).
- **Amos Tversky** (1937-1996): Prospect theory, framing effects.
- **Jean Piaget** (1896-1980): Cognitive development stages; schemas.
- **Noam Chomsky** (1928-): Critique of behaviorism via language acquisition.
- **Herbert Simon** (1916-2001): Bounded rationality; artificial intelligence.

## Bridging Figures
- Bandura (social cognitive theory)
- Aaron Beck & Albert Ellis: Cognitive therapy foundations
