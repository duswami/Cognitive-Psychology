# Cognitive Psychology

Core documents and summaries on behavioral and cognitive psychology. Prepared for continued study and reference.

## Contents
- `behavioral-psychology.md` — Behaviorism, conditioning, reinforcement, key researchers.
- `cognitive-psychology.md` — Mental processes, memory, attention, decision-making.
- `key-concepts.md` — Bridging concepts between the two fields.
- `key-researchers.md` — Historical figures.

## ML Framework
- `ml_framework.py` — Lightweight classifier that maps questions to relevant docs and researchers. Pure Python, no external dependencies.
- `knowledge_base.json` — Structured index of topics and researchers for matching.
- `question_log.md` — Running log of questions, classifications, and cross-references.

## Usage
Run `python ml_framework.py` to test classification. New questions get logged and cross-referenced with historical psychologists (Pavlov, Skinner, Piaget, Ebbinghaus, etc.).

Ready for prompts.
